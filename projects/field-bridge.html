What this means for engineering & operations

When plant equipment runs on fragmented vendor protocols, downstream applications face high integration fragility and data loss. This gateway abstracts hardware differences into a unified event stream, backed by local SQLite buffering to guarantee zero dropped telemetry during network disruptions.

Three-tier field-to-application architecture

The gateway decouples physical operational technology (OT) from downstream software clients across three deterministic processing layers.

01 / INGESTION Field Drivers

Physical OT Ingestion

Pluggable asynchronous protocol adapters polling Modbus TCP (:5020), subscribing to OPC UA monitored items (:4840), and reading Siemens S7 DB blocks via Snap7. Each device connection runs in an isolated task loop to prevent field faults from cascading.

Non-blocking socket polling · Hardware fault isolation
02 / NORMALIZATION WAL Buffer

Async Normalization & Buffering

A Python asyncio engine parses raw registers into clean semantic keys, applies engineering unit scaling, evaluates value deadbands, and logs to a transactional SQLite write-ahead buffer during link drops. Ensures deterministic processing before distribution.

Zero dropped telemetry · Atomic store-and-forward
03 / BROADCAST WebSockets

Real-Time Stream Broadcast

A high-throughput WebSocket server (:8765) broadcasting structured JSON telemetry frames to the Unity 3D process twin, web monitoring dashboards, and SCADA analytics clients with sub-15ms fan-out latency.

Sub-15ms broadcast latency · Decoupled multi-client fan-out

Resilient edge ingestion under hostile plant conditions

Designed specifically for mission-critical industrial facilities where network stability cannot be guaranteed and hardware configurations evolve over time.

01 / BUFFERING Store & Forward

Store-and-Forward Edge Buffering

If the plant network or upstream link drops, telemetry writes atomically to a local SQLite Write-Ahead Log (WAL) buffer on the Industrial PC's solid-state storage. Once reconnected, backlogged records replay in strict FIFO order without blocking concurrent live acquisition or causing duplicate keys.

SQLite WAL mode · Zero telemetry loss across dropouts
02 / NORMALIZATION Clean Data Layer

Multi-Protocol Normalization

Translates raw, cryptic PLC registers into clean, readable tag names before data reaches downstream apps. Visual twins and dashboards simply listen for "TankLevel" or "AgitatorSpeed" without having to worry about hardware-specific binary formats or vendor offsets.

Clean semantic tags · Vendor-agnostic stream
03 / DEPLOYMENT Zero Code Edits

Declarative JSON Configuration

Engineers deploy and tune gateway instances onto headless Industrial PCs via declarative JSON configuration files. Tag mappings, scale multipliers, deadbands, and per-device polling intervals (50–100 ms) are adjusted in the field without recompiling or modifying Python source code.

Declarative schema · Field-adjustable polling intervals
04 / RELIABILITY Signal Integrity

Quality & Heartbeat Supervision

Appends ISO-8601 UTC timestamps, engineering units, and standard quality state flags (GOOD, DEGRADED, COMM_FAILURE) to every tag payload. Watchdog timers detect hung PLC sockets immediately instead of leaving clients with misleading stale values.

Watchdog heartbeat · Explicit stale-data signaling
